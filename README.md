# AfterShot

Ứng dụng chỉnh màu ảnh theo bộ màu (look), thêm khung thông tin máy ảnh, chạy ngay trên trình duyệt hoặc dưới dạng app Android.

- Chỉnh màu hàng loạt với các bộ màu dựng sẵn
- Thêm khung với logo hãng máy ảnh và điện thoại
- Xử lý hoàn toàn trên thiết bị, ảnh không được tải lên máy chủ
